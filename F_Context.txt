# YARKIB PROJECT - COMPLETE CONTEXT DOCUMENT

## PROJECT OVERVIEW
Yarkib is a React Native/Expo mobile application for cyclists and route planning. It's built using Expo Router v5, React Native 0.79.6, and React 19.0.0. The app allows users to discover, save, and complete cycling routes with features like elevation profiles, OAuth authentication, and route management.

## AUTHENTICATION SYSTEM

### OAuth Providers
- **Google**: Uses web client ID with mobile-specific redirect URIs
- **Apple**: Sign in with Apple integration
- **Email/Password**: Traditional authentication flow

### OAuth Flow Details
1. **Mobile OAuth**: Uses Custom Tabs (`expo-web-browser`) instead of WebView
2. **Redirect URIs**: 
   - Mobile: `${API_BASE}/auth/mobile/callback`
   - Web: `${API_BASE}/auth/callback`
3. **Deep Linking**: Handles OAuth callbacks via `yarkib://oauth/callback` scheme
4. **Session Management**: Stores user data in `expo-secure-store`

### Authentication Context Features
- **State Management**: User, loading, authentication status
- **Storage**: Secure token storage with fallback to localStorage for web
- **Error Handling**: Comprehensive error handling for OAuth failures
- **Mock Mode**: Development mode with simulated authentication

## API INTEGRATION

### Configuration
- **Base URLs**: Configurable per environment (dev, staging, production)
- **Timeouts**: 5s for connection checks, 10s for API calls
- **Mock Mode**: Toggle between real API and mock data

### API Endpoints
- **Authentication**:
  - `POST /auth/email/signup` - User registration
  - `POST /auth/email/login` - User login
  - `POST /auth/mobile/signin` - Mobile OAuth initiation
  - `GET /auth/mobile/session` - Mobile session status
  - `GET /auth/session` - Web session status
  - `GET /auth/user` - User information

- **Routes**:
  - `GET /routes` - List all routes
  - `GET /routes/{id}/elevation` - Route elevation data
  - `POST /user/routes/{id}/save` - Save route
  - `DELETE /user/routes/{id}/save` - Unsave route
  - `POST /user/routes/{id}/complete` - Complete route
  - `GET /user/routes` - User's saved/completed routes

- **Profile**:
  - `GET /me` - User profile
  - `GET /me/stats` - User statistics
  - `GET /me/saved-routes` - Saved routes
  - `GET /me/completed-rides` - Completed rides
  - `PUT /me/summary` - Update user summary

### Mock Data System
- **Route Data**: 3 sample routes with realistic data
- **Elevation Profiles**: Generated elevation data with mathematical functions
- **User Data**: Mock user profiles and authentication responses
- **API Simulation**: Simulates network delays and responses

## ROUTE MANAGEMENT

### Route Data Structure
```typescript
interface Route {
  id: string;                   // UUID
  name: string;                 // Route name
  description?: string;         // Route description
  distance: number;             // Distance in kilometers
  duration: number;             // Duration in minutes
  difficulty: 'easy' | 'intermediate' | 'hard';
  elevation_gain?: number;      // Elevation gain in meters
  start_location?: {            // Starting coordinates
    latitude: number;
    longitude: number;
    address?: string;
  };
  end_location?: {              // Ending coordinates
    latitude: number;
    longitude: number;
    address?: string;
  };
  start_point_name?: string;    // Starting point name
  end_point_name?: string;      // Ending point name
  route_points?: Array<{        // Route waypoints
    latitude: number;
    longitude: number;
  }>;
  elevation_profile?: Array<{   // Elevation data
    distance: number;           // Distance from start (km)
    elevation: number;          // Elevation (meters)
  }>;
  max_elevation?: number;       // Maximum elevation
  category_id?: string;         // Category UUID
  images?: string[];            // Route images
  rating?: number;              // Average rating (0-5)
  review_count?: number;        // Number of reviews
  tags?: string[];              // Route tags
  gpx_file_url?: string;       // GPX file download
  google_maps_url?: string;     // Google Maps link
}
```

### Route Features
- **Elevation Charts**: Interactive elevation profiles using SVG
- **Difficulty Indicators**: Color-coded difficulty levels
- **External Links**: GPX downloads and Google Maps integration
- **Tag System**: Categorization and filtering
- **Save/Complete**: User interaction with routes
