# Placeholder Images

This directory should contain the following placeholder images:

1. `icon.png` - App icon (1024x1024px)
2. `splash.png` - Splash screen (2048x2048px)
3. `adaptive-icon.png` - Android adaptive icon (1024x1024px)
4. `welcome.png` - Welcome screen illustration

You can generate these placeholder images using online tools or design software.

## Quick Solution

For now, you can rename the SVG files in the parent directory:

1. Convert `../icon.svg` to `icon.png`
2. Convert `../splash.svg` to `splash.png` 
3. Convert `../icon.svg` to `adaptive-icon.png`

## Online Tools for SVG to PNG Conversion

- [Convertio](https://convertio.co/svg-png/)
- [CloudConvert](https://cloudconvert.com/svg-to-png)
- [SVG2PNG](https://svgtopng.com/)
